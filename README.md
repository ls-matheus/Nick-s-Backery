# 🧁 Nick's Bakery

Portfólio oficial interativo de cosplays e marca **Nick's Bakery**.

---

## 📁 Estrutura do Projeto

```
Nick-s-Bakery/
├── Backend/
│   ├── NavSystem.js         # Lógica de navegação SPA, efeito parallax 3D e indicador
│   └── liquid.js            # Engine de partículas e efeito líquido (Gooey Filter Canvas)
├── Nav/
│   ├── Home.html            # Estrutura principal da página inicial
│   ├── Sell.html            # Página de vendas
│   ├── Server.html          # Página do servidor
│   └── View.html            # Galeria de cosplays
├── src/
│   ├── js/                  # Scripts modulares (core & componentes)
│   ├── pages/               # Páginas do SPA (home.html, view.html, sell.html, server.html)
│   └── styles/              # Camadas de estilos modulares (base, layouts, components)
├── assets/
│   ├── final/               # Imagens de avatares e ícones decorativos
│   └── random/              # Recursos gráficos auxiliares
├── docs/                    # Documentação do repositório
│   ├── ARCHITECTURE.md      # Visão geral da arquitetura
│   └── DESIGN_SYSTEM.md     # Guia do sistema de design e tokens
├── .github/
│   └── workflows/
│       └── ci.yml           # Integridade contínua (CI)
├── main.html                # Entrypoint HTML principal
├── package.json             # Scripts e gerenciamento NPM
├── .editorconfig
├── .eslintrc.json
├── .gitignore
├── .prettierrc
├── LICENSE
└── README.md
```
